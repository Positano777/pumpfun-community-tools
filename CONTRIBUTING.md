# Contributing

Open an issue with the observed behavior, expected behavior, public transaction references, and coverage limits. Redact credentials. Distinguish synthetic fixtures from observed mainnet results.

Before a PR, run `npm test` and `npm run typecheck`. Detection changes also require the mainnet scan required by AGENTS.md. Preserve upstream attribution, include meaningful fixtures, and avoid presenting correlations as proof of common control. Do not change program IDs without mainnet verification. Contributions are MIT licensed.
